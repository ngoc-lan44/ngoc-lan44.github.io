# Worklog Tuần 11: Nâng cấp Core Backend & Kiến trúc Kiểm duyệt (Moderation Phase 3)

### Mục tiêu Tuần 11:

- Chuyển đổi cơ chế Soft-Delete từ lưu trữ file S3 sang hệ thống giao dịch ACID trên Amazon DynamoDB nhằm đảm bảo tính toàn vẹn dữ liệu.

### Các công việc cần triển khai trong tuần này:

|   Thứ   | Công việc | Ngày bắt đầu | Ngày hoàn thành | Nguồn tài liệu |
| :-----: | :-------- | :----------: | :-------------: | :------------- |
| **Thứ 2** | **Thiết kế Data Model DynamoDB:** Phân rã dữ liệu kiểm duyệt thành 2 bảng: Bảng trạng thái (State Table, partition key `record_id`) và bảng nhật ký (Audit Table, sort key theo `revision`). | 19/10/2026 | 19/10/2026 | `SOFT_DELETE_PHASE3.md` |
| **Thứ 3** | **Lập trình Transaction (ACID):** Phát triển logic `TransactWriteItems` trong `dynamo_moderation_store.py` ghi đồng thời metadata, trạng thái việc làm và log sự kiện, ngăn chặn Race Condition. | 20/10/2026 | 20/10/2026 | `SOFT_DELETE_PHASE3.md`, `SOFT_DELETE_PHASE3_FULL_CODE.md` |
| **Thứ 4** | **Cơ chế S3 Projection:** Viết luồng đồng bộ định kỳ snapshot từ DynamoDB lên S3 và cập nhật View trên Amazon Athena sang snapshot v3, giữ BI Dashboard hoạt động mượt mà. | 21/10/2026 | 21/10/2026 | `SOFT_DELETE_PHASE3.md`, `SOFT_DELETE_PHASE3_FULL_CODE.md` |
| **Thứ 5** | **Viết Script Migration (Phase 2 to Phase 3):** Lập trình `deploy_moderation_phase3.py` để khóa (fence) bản ghi S3 cũ và sao chép audit log sang DynamoDB theo cơ chế idempotent, tự phục hồi. | 22/10/2026 | 22/10/2026 | `SOFT_DELETE_PHASE3.md`, `SOFT_DELETE_PHASE3_FULL_CODE.md` |
| **Thứ 6** | **Tối ưu hiệu năng (Performance Tuning):** Tinh chỉnh Cache bằng memoization an toàn với `ContextVar` và cấu trúc lại AWS SDK calls, giảm thời gian tải trang Tổng quan từ 409ms xuống 260ms. | 23/10/2026 | 23/10/2026 | `PERFORMANCE_LOCAL.md`, `performance_results.json` |

### Kết quả Tuần 11:

Chuyển đổi thành công backend kiểm duyệt sang DynamoDB ACID Transaction, đồng bộ mượt mà với S3/Athena và giảm ~36% độ trễ tải trang Dashboard.
