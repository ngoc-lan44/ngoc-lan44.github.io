# Worklog Week 6: Amazon S3 and AWS CLI Operations

### Week 6 Objectives:

- Understand Amazon S3 object storage architecture, create and manage buckets, configure storage classes, and automate file operations using the AWS Command Line Interface (CLI).

| **Tue** | Create S3 buckets, upload objects, configure metadata, and host a static website directly on Amazon S3. | 15/09/2026 | 15/09/2026 | [Cloud Journey – Amazon S3](https://cloudjourney.awsfcaj.com/) |

| **Fri** | Configure S3 Lifecycle Rules to automatically transition objects between storage classes and expire old data. | 18/09/2026 | 18/09/2026 | [Cloud Journey – Amazon S3](https://cloudjourney.awsfcaj.com/) |

Successfully managed object storage on Amazon S3, automated data synchronization via AWS CLI, and optimized storage costs with lifecycle policies.
