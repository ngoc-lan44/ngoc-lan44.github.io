# Worklog Week 7: S3 Security and Data Protection

### Week 7 Objectives:

- Implement granular access controls for Amazon S3 using Bucket Policies and Block Public Access, enforce encryption in transit and at rest, and protect data against accidental deletion using Versioning and Cross-Region Replication.

### Tasks to Implement This Week:

| Day | Taskgi | Start Date | Completion Date | Reference |
| **Mon** | Configure S3 Block Public Access settings at both account and bucket levels, and write JSON Bucket Policies to restrict unauthorized access. | 21/09/2026 | 21/09/2026 | [Cloud Journey – S3 Security](https://cloudjourney.awsfcaj.com/) |
| **Tue** | Configure Server-Side Encryption using Amazon S3 managed keys (SSE-S3) and AWS KMS keys (SSE-KMS), and enforce HTTPS-only access via Bucket Policy. | 22/09/2026 | 22/09/2026 | [Cloud Journey – S3 Security](https://cloudjourney.awsfcaj.com/) |
| **Wed** | Enable S3 Versioning to protect against accidental overwrites and deletions, and practice restoring previous object versions. | 23/09/2026 | 23/09/2026 | [Cloud Journey – S3 Data Protection](https://cloudjourney.awsfcaj.com/) |
| **Thu** | Generate S3 Pre-signed URLs via AWS CLI to grant temporary, time-limited access to private objects without making the bucket public. | 24/09/2026 | 24/09/2026 | [Cloud Journey – S3 Security](https://cloudjourney.awsfcaj.com/) |
| **Fri** | Configure S3 Cross-Region Replication (CRR) and Server Access Logging to ensure disaster recovery and audit trail compliance. | 25/09/2026 | 25/09/2026 | [Cloud Journey – S3 Data Protection](https://cloudjourney.awsfcaj.com/) |

### Results:

Successfully hardened Amazon S3 buckets against unauthorized public exposure, enforced end-to-end encryption, and established versioning and replication safeguards for critical data.
