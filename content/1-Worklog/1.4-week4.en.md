# Worklog Week 4: Amazon EC2, EBS, and Server Management

### Week 4 Objectives:

- Understand Amazon EC2 compute services, configure virtual machines, manage EBS storage volumes, and establish secure remote server access.

Successfully launched and managed EC2 instances, configured persistent EBS storage with snapshot backups, and automated initial server provisioning.
