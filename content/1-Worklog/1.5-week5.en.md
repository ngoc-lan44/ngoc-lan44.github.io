# Worklog Week 5: IAM Roles for EC2 and Session Manager

### Week 5 Objectives:

- Understand how to attach IAM Roles to EC2 instances for secure AWS service access without storing access keys, and use AWS Systems Manager Session Manager for keyless shell access.

### Tasks to Implement This Week:

| Day | Task | Start Date | Completion Date | Reference |
| **Mon** | Learn the security risks of hardcoding AWS credentials on EC2 and how IAM Instance Profiles solve this problem. | 07/09/2026 | 07/09/2026 | [Cloud Journey – IAM Role & SSM](https://cloudjourney.awsfcaj.com/) |
| **Tue** | Create an IAM Role with S3 and Systems Manager permissions (`AmazonSSMManagedInstanceCore`) and attach it to an EC2 instance. | 08/09/2026 | 08/09/2026 | [Cloud Journey – IAM Role & SSM](https://cloudjourney.awsfcaj.com/) |
| **Wed** | Test temporary credential retrieval via EC2 Instance Metadata Service (IMDSv2) and verify S3 access from EC2 CLI. | 09/09/2026 | 09/09/2026 | [Cloud Journey – IAM Role & SSM](https://cloudjourney.awsfcaj.com/) |
| **Thu** | Configure AWS Systems Manager Session Manager to connect to private EC2 instances without opening port 22 or managing SSH keys. | 10/09/2026 | 10/09/2026 | [Cloud Journey – IAM Role & SSM](https://cloudjourney.awsfcaj.com/) |
| **Fri** | Enable Session Manager audit logging to Amazon S3 and CloudWatch Logs to track administrative commands. | 11/09/2026 | 11/09/2026 | [Cloud Journey – IAM Role & SSM](https://cloudjourney.awsfcaj.com/) |

Successfully configured IAM Roles for EC2 and established secure, SSH-free remote server access via AWS Systems Manager Session Manager with full session logging.
