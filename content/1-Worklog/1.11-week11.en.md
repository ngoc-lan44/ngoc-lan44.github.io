# Worklog Week 11: Amazon Athena and SQL Data Analysis

### Week 11 Objectives:

- Query structured and semi-structured datasets directly on Amazon S3 using serverless standard SQL via Amazon Athena, optimize query performance and scan costs through partitioning and columnar formats, and extract analytical insights from the IT recruitment dataset.

### Tasks to Implement This Week:

| Day | Task | Start Date | Completion Date | Reference |
| **Mon** | Explore Amazon Athena serverless architecture (Presto/Trino engine), configure an S3 query result output bucket, and set up Athena Workgroups with data scan limits. | 19/10/2026 | 19/10/2026 | [Cloud Journey – Amazon Athena](https://cloudjourney.awsfcaj.com/) |
| **Tue** | Connect Amazon Athena to the AWS Glue Data Catalog and execute SQL queries (`SELECT`, `GROUP BY`, `JOIN`, window functions) on IT recruitment job posting tables. | 20/10/2026 | 20/10/2026 | [Cloud Journey – Amazon Athena](https://cloudjourney.awsfcaj.com/) |
| **Wed** | Practice query optimization techniques: compare data scanned and execution time between raw CSV/JSON vs. partitioned Apache Parquet datasets (`WHERE year='2026'`). | 21/10/2026 | 21/10/2026 | [Cloud Journey – Amazon Athena](https://cloudjourney.awsfcaj.com/) |
| **Thu** | Create SQL Views and use `CREATE TABLE AS SELECT` (CTAS) statements to transform, aggregate, and materialize clean analytical tables for downstream BI reporting. | 22/10/2026 | 22/10/2026 | [Cloud Journey – Amazon Athena](https://cloudjourney.awsfcaj.com/) |
| **Fri** | Run analytical SQL queries to extract market insights (top required technical skills, salary ranges by role/experience, and hiring demand trends across cities). | 23/10/2026 | 23/10/2026 | [Cloud Journey – Amazon Athena](https://cloudjourney.awsfcaj.com/) |

### Results:

Successfully executed serverless SQL analytics on Amazon S3 using Amazon Athena, reduced query scan costs through partitioning and Parquet optimization, and generated key IT recruitment market insights.
