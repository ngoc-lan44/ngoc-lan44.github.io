# Worklog Week 10: Data on S3 and AWS Glue Data Catalog

### Week 10 Objectives:

- Design a structured Data Lake architecture on Amazon S3 (Raw, Processed, Curated zones), optimize analytical file formats (Parquet/CSV/JSON), and automate metadata discovery and schema cataloging using AWS Glue Data Catalog and Crawlers.
