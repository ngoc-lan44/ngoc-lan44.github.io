### Strengths in the learning journey

- **Connecting knowledge with real systems:** understand the role of Python on EC2, Parquet on S3, Glue metadata and Athena queries in the data flow of the Vietnam IT Job Market.
- **Distinguishing responsibilities of components:** recognize personal accounts and activities stored on S3, while moderation and audit are stored on DynamoDB; understand the synchronization role of the Projection Worker.
- **Proactively cross-checking documentation and source code:** check configurations, commands, and test results at each point in time, avoiding the assumption that a feature in the source code is proof that it has worked on AWS.
- **Practicing report writing:** organize the worklog, proposal, and workshop sequentially so readers can trace the steps and verify the results.

### Areas for improvement to be ready for future projects

- **Technical depth:** need more practice optimizing Athena queries, IAM permissions, and operational costs based on actual metrics.
- **Operations and recovery:** need to continue practicing reading logs, handling pipeline errors, verifying backup/restore, and EC2 restart scenarios; not considering un-rehearsed scenarios as mastered.
- **Technical presentation:** need to explain more concisely, use diagrams, actual images, and results with dates or run/query IDs for illustration.
- **Testing:** need to improve the ability to design integration test scenarios and measure performance; distinguish offline test results from actual AWS acceptance.
- **Schedule management:** need to update notes regularly and break down tasks to detect obstacles earlier.

### Post-internship orientation

I want to continue developing in the direction of **Python / Data Engineering / Cloud**, consolidating skills in data processing, query design, security, and operations on AWS. I will continue to perfect the Vietnam IT Job Market with tested improvements and actual evidence, while practicing document presentation to be ready for future projects.
