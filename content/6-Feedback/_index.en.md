This section contains my personal takeaways and perspectives — **Nguyễn Ngọc Lan**, an Information Technology student in class **K68CNTTB** at **Vietnam National University of Agriculture** — after 12 weeks of participating in the **First Cloud AI Journey** program and the **Vietnam IT Job Market** project. The following assessments are written from the perspective of an IT student gradually turning theory into practical skills on the cloud computing platform.

### Evaluation by aspect

**1. Learning environment and methodology**

Instead of cramming theory, the program guided us to approach AWS through practical hands-on labs. Applying the storage and processing of IT recruitment data into practice helped me deeply understand the nature of each service, rather than just memorizing their names. I learned the habit of carefully reading the documentation and checking configurations before hitting the "Deploy" button.

**2. Documentation and support culture**

The documentation system on Cloud Journey is logically organized and easy to look up when forgotten. Additionally, the program's "ask right - answer direct" culture helped me practice my error description (debug) skills, providing the correct logs/error messages instead of asking vague questions. This is an extremely important technical communication skill for my future career.

**3. Connection to specialized knowledge**

The Vietnam IT Job Market project is a perfect demonstration of a real-world Data Pipeline: from running Python scripts to collect data on EC2, pushing Parquet files to S3, using Glue Data Catalog to define structures, to using Athena for querying. It helped me connect all the fragmented knowledge about networking, storage, and databases learned at school.

**4. Most noticeably improved skills**

- The mindset of looking up specialized English documentation and understanding AWS system architecture.
- Carefulness and discipline when assigning IAM Roles and Security Groups to ensure security.
- The ability to read CloudWatch logs to independently isolate and troubleshoot issues.
- Skills in synthesizing, editing documents, and presenting technical reports visually and clearly (leveraging my personal strengths from media and union activities).

### Feedback questions

**What am I most satisfied with?**

I am most proud of my progress in being able to independently operate the core components of a data system. Starting with a lot of confusion, I now clearly understand why S3 is used instead of a traditional Database for a Data Lake, or how to optimize a query on Athena. Having all results backed by logs or Query IDs helps me work with solid evidence and much more confidence.

**What should the program improve?**

- Add short exchange sessions (mini-workshops) between internship groups to analyze different solutions for the same problem.
- Provide more documentation or checklists related to **Cost Optimization** right from the first labs, helping students form a mindset of saving cloud resources early on.
- Create a shared Knowledge Base compiling classic troubleshooting cases from previous cohorts for newcomers to easily reference.

**Would I recommend the program to friends?**

Definitely yes. This is an ideal "combat" environment for proactive students who are not afraid to read English documentation and want to improve their independent problem-solving abilities.

### Further suggestions and orientation

- **Promote operational practice (Operations):** I hope the program adds hypothetical scenarios (e.g., pipeline failing halfway, EC2 crashing) so interns can practice system recovery (Backup/Restore).
- **Personal orientation:** After the internship, I plan to continue delving into **Python, Data Engineering, and Cloud Computing**. I will further refine the visualization (Dashboard) for the Vietnam IT Job Market project and pursue additional AWS certifications to expand career opportunities.

**Acknowledgments**

I would like to express my sincere gratitude to the Mentors at AWS Vietnam, the First Cloud AI Journey community, and my fellow interns in the group. This 12-week journey not only equipped me with sharp technical knowledge but also helped me shape a more independent, professional, and responsible working mindset — an invaluable asset for my IT career ahead.
