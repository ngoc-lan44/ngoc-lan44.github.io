# Báo cáo thực tập Vietnam IT Job Market

Báo cáo cá nhân Tòng Văn Tâm tại Amazon Web Services.

Giao diện sử dụng nguyên bản mẫu Hugo, logo AWS và màu theme workshop.

Gồm sáu mục: Nhật kí công việc; Bản đề xuất; Các sự kiện meetup đã tham gia; Workshop; Tự đánh giá; Chia sẻ, đóng góp ý kiến.

Lịch worklog: 12 tuần học AWS từ 10/08 đến 06/11/2026, bỏ qua tuần có ngày 2/9. Nội dung dựa trên Cloud Journey, gồm tài khoản/Budgets/Support, IAM, VPC, EC2/Role/SSM, S3/CLI/bảo mật, DynamoDB/SDK/transaction, Glue Data Catalog, Athena và CloudWatch.

Chạy `hugo server` để xem website. Mở vietnam-it-job-market-review.html để đọc nội dung cùng logo và CSS gốc.
