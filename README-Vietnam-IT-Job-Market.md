# Báo cáo thực tập Vietnam IT Job Market

Báo cáo của Tòng Văn Tâm, gồm sáu mục: Nhật ký công việc; Bản đề xuất; Các sự kiện meetup đã tham gia; Workshop; Tự đánh giá; Chia sẻ, đóng góp ý kiến.

- `content/`: nội dung báo cáo tiếng Việt và tiếng Anh.
- `static/`: ảnh, phông chữ, CSS và JavaScript dùng trên website.
- `layouts/`: giao diện tùy chỉnh của báo cáo.
- `themes/hugo-theme-learn/`: giao diện Hugo và thư viện phục vụ hiển thị, tìm kiếm, điều hướng.
- `config.toml`: cấu hình website.
- `.github/workflows/`: cấu hình xuất bản website lên GitHub Pages.
- `vietnam-it-job-market-review.html`: trang xem trước độc lập.

Chạy `hugo server` tại thư mục này để xem website Hugo. Có thể mở trực tiếp `vietnam-it-job-market-review.html` để xem bản báo cáo độc lập.

Các file hướng dẫn chụp ảnh Workshop được giữ để bổ sung ảnh cho báo cáo.
